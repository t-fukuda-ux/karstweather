# 雲海予報の履歴

各日18:00〜23:59 JSTの最初の有効な翌朝予報を、モデルごとに保存します。
翌朝の指数が全欠測なら保存を見送り、その日の次の更新で再試行します。
同じ日・モデルの既存ファイルは上書きしません。欠けた日は予報履歴なしとして扱います。

JSONの issued_at は取得・計算完了時刻で、気象モデルの初期時刻ではありません。
source_revision、モデル、平均版の混成・代替状況と、対象日時付きの詳細CSV・気圧面CSVを含みます。
ローカルの forecast-runs/ には各実行の履歴を残します（git対象外）。
Actionsでは夕方の履歴だけをgitへ保存し、毎回の forecast-runs/ は実行終了後に残りません。
このフォルダは公開リポジトリ・GitHub Pagesから閲覧可能です。現地記録や個人情報は含めません。

比較時は issued_at が観測前であることを確認し、detail_rows の date/time と現地記録を結合します。
谷が見えない日はFの評価から除外し、Vだけを検証します。旧予報を現在の式で再計算した値と混同しないでください。
同時実行の競合では複数残る場合があります。発表時刻付きの別ファイル名で両方を保持し、比較には issued_at が最も早いものを選びます。
