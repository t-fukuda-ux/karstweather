# 週間予報の履歴

各日18:00 JST以降の最初の有効な実行で、7日分の週間予報を版ごとに保存します（2026-09-25〜）。
同じ日・版の既存ファイルは上書きしません。気温が1日分も無い応答なら保存を見送り、その日の次の更新で再試行します。

- ファイル: `YYYY-MM-DD/版-HHMMSS.csv`（版は best_match / ecmwf_ifs025 / average）
- `lead_days` は発表日から何日先か（0＝発表当日）
- `tmax_disp` / `tmin_disp` は画面表示用の補正後の気温、`tmax_raw` / `tmin_raw` はモデルそのままの気温
- `pop_max` は日最大の降水確率、`precip_sum` は日降水量（mm）、`snow_sum` は日降雪量（cm、平均版のみ）
- `weather` は画面の天気の文言。平均版は数値から推定した複合表現で、`wcode` は空
- `issued_at` は取得・計算完了時刻（JST）で、モデルの初期時刻ではありません

何日先まで当たるかは、実測（アメダス等）と `target_date` で結合して評価します。
